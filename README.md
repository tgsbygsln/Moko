MoKo – Real Estate Web Application

Overview

MoKo is a real estate rental and sales web application developed as my graduation project.
The system allows users to post property listings, search and filter properties, and view detailed information.

Features
	•	Create property listings
	•	Search and filter listings
	•	View property details
	•	Basic CRUD operations

Tech Stack
	•	Backend: ASP.NET MVC / ASP.NET Core MVC
	•	Frontend: HTML, CSS, JavaScript
	•	Database: MySQL
	•	Architecture: MVC (Model–View–Controller)

System Structure
	•	Frontend: User interface for listing, searching, and viewing properties
	•	Backend: Controllers handle business logic and requests
	•	Database: Stores users and property listing data

Database Design
	•	Designed ERD for users and property listings
	•	Applied primary key and foreign key relationships
